# Tarefa CSS

Este repositório contém uma tarefa de CSS que demonstra o uso de estilos e layouts em páginas web.

## Descrição

A Tarefa CSS é um projeto que visa praticar a aplicação de estilos em HTML através de CSS. O projeto inclui exemplos de diferentes propriedades CSS, como cores, fontes, espaçamento e layout.

## Estrutura do Projeto

- `index.html`: O arquivo HTML principal que contém a estrutura da página.
- `styles.css`: O arquivo CSS que define os estilos para a página.
- `images/`: Pasta que contém imagens utilizadas no projeto.
